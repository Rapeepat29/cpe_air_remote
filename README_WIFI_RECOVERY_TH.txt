============================================================

RMUTT Save Energy - อัปเดตแก้รหัส Wi-Fi ผิด
================================================

สิ่งที่แก้ไข
- ESP32 ทดสอบชื่อ Wi-Fi และรหัสผ่านก่อนบันทึกลง NVS
- หากรหัสผิด แอปจะแจ้งข้อผิดพลาดและยังอยู่ในหน้าตั้งค่าเดิม
- แก้รหัสแล้วกดบันทึกซ้ำได้ทันที โดยไม่ต้องล้าง Flash
- ค่าที่เคยใช้งานได้จะไม่ถูกเขียนทับด้วยรหัส Wi-Fi ที่ทดสอบไม่ผ่าน
- หากค่าที่บันทึกไว้เชื่อมต่อไม่ได้หลังเปิดเครื่อง ESP32 จะเปิด Bluetooth
  recovery mode อัตโนมัติ
- ยังสามารถกด BOOT ค้างขณะกด Reset เพื่อเข้าโหมดตั้งค่าใหม่ได้เสมอ
- รวมความสามารถสแกน Wi-Fi ผ่าน ESP32 จากอัปเดตก่อนหน้าไว้แล้ว

วิธีติดตั้ง
1. ปิด flutter run ด้วย Ctrl+C
2. แตก ZIP นี้ลงในโฟลเดอร์ cpe_air_remote
3. เลือก Replace the files in the destination
4. เปิด firmware/rmutt_esp32_air/rmutt_esp32_air.ino
5. อัปโหลดเฟิร์มแวร์ใหม่โดยใช้ Partition Scheme: No FS 4MB (2MB APP x2)
   (เฟิร์มแวร์ปัจจุบันใช้ partitions.csv ในโฟลเดอร์สเก็ตช์ ไม่ใช่ Huge APP แล้ว)
6. เปิด PowerShell ในโฟลเดอร์ cpe_air_remote แล้วรัน:

   flutter clean
   flutter pub get
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api

วิธีทดสอบ
1. กด BOOT ค้างแล้วกด Reset เพื่อเปิด Bluetooth
2. เปิดเมนูตั้งค่า ESP32 ในแอป
3. เลือก SSID แล้วตั้งใจกรอกรหัส Wi-Fi ผิด
4. กดบันทึก รอไม่เกินประมาณ 15 วินาที
5. แอปต้องแจ้งว่าเชื่อมต่อ Wi-Fi ไม่สำเร็จ และยังไม่ปิดหน้าตั้งค่า
6. แก้รหัสให้ถูก แล้วกดบันทึกอีกครั้ง
7. เมื่อผ่าน แอปจะแจ้งว่าตรวจสอบ Wi-Fi และบันทึกการตั้งค่าแล้ว

หมายเหตุ
- ESP32 รองรับ Wi-Fi 2.4 GHz เท่านั้น
- MQTT Host ของ ESP32 ใช้ IP LAN ของคอม เช่น 192.168.1.153
- Backend .env ใช้ mqtt://127.0.0.1:1883 เมื่อ Backend และ Broker
  ทำงานอยู่บนคอมเครื่องเดียวกัน
