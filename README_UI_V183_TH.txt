RMUTT Save Energy - อัปเดตวันปัจจุบันในหน้าตาราง
=====================================================

เวอร์ชันแอป: 3.3.3+13

สิ่งที่เปลี่ยน
-------------
1. เมื่อเปิดหน้าตารางใช้งานห้องครั้งแรก ระบบจะเลือกวันปัจจุบันจากวันที่
   ของเครื่องโดยอัตโนมัติ
2. ใต้หัวข้อจะแสดงคำว่า "วันนี้" พร้อมวันและวันที่จริง เช่น
   "วันนี้ · พฤ. 30 ก.ค. 2569"
3. เมื่อเลือกวันอื่น ระบบจะแสดง "วันที่เลือก" พร้อมวันที่ของวันนั้นใน
   สัปดาห์ปัจจุบัน
4. รองรับวันครบทั้ง 7 วัน ภาษาไทย/อังกฤษ และปี พ.ศ. สำหรับภาษาไทย

วิธีติดตั้ง
-----------
1. นำโฟลเดอร์ cpe_air_remote ไปทับโปรเจกต์เดิม
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์
3. รันคำสั่ง:

   flutter clean
   flutter pub get
   flutter test
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

ไม่ต้องแก้ฐานข้อมูล Backend หรือแฟลช ESP32 ใหม่
