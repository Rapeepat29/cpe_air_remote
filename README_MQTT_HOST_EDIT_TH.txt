อัปเดตช่อง MQTT Host
======================

สิ่งที่แก้
-----------
- ช่อง MQTT Host / IP สามารถคลิก ลบ และพิมพ์ค่าใหม่ได้
- ค่าเริ่มต้นเป็น 192.168.1.153
- มีปุ่ม X สำหรับล้างค่าเดิม
- สามารถกำหนดค่าเริ่มต้นตอนรันด้วย MQTT_DEFAULT_HOST
- ไม่กระทบฟังก์ชันสแกน Wi-Fi หรือระบบแก้รหัส Wi-Fi ผิด
- ไม่ต้องอัปโหลดเฟิร์มแวร์ ESP32 ใหม่สำหรับอัปเดตนี้

วิธีติดตั้ง
-----------
1. แตก ZIP นี้ทับโฟลเดอร์ cpe_air_remote
2. เลือก Replace the files
3. เปิด cpe_air_remote/backend/.env
4. ตั้งค่า MQTT_URL ให้ใช้ IP เดียวกับที่จะกรอกในแอป:

   MQTT_URL=mqtt://192.168.1.153:1883

5. ปิด Backend เดิมด้วย Ctrl+C แล้วเปิดใหม่:

   cd backend
   npm run dev

6. เปิด PowerShell อีกหน้าหนึ่งที่โฟลเดอร์ cpe_air_remote แล้วรัน:

   flutter clean
   flutter pub get
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

ค่าที่ใช้ในหน้าตั้งค่า ESP32
-----------------------------
MQTT Host: 192.168.1.153
MQTT Port: 1883

ข้อสำคัญ
---------
- ในช่อง MQTT Host ให้ใส่เฉพาะ 192.168.1.153
- อย่าใส่ mqtt:// และอย่าใส่ :1883 ต่อท้าย เพราะ Port มีช่องแยก
- 127.0.0.1 บน ESP32 หมายถึงตัว ESP32 เอง จึงเชื่อม Broker บนคอมไม่ได้
- ถ้า IP ของคอมเปลี่ยน สามารถล้างแล้วพิมพ์ IP ใหม่ได้ แต่ต้องแก้ MQTT_URL
  ใน backend/.env ให้เป็น IP เดียวกันและรีสตาร์ต Backend ทุกครั้ง
