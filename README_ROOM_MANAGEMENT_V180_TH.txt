RMUTT Save Energy v1.8.0
ระบบชื่ออาจารย์และจัดการห้อง
========================================

สิ่งที่เพิ่ม
1. แสดงชื่ออาจารย์ในหน้าตารางเรียน หน้าจัดการ และตัวอย่าง Excel
2. เก็บชื่อวิชา กลุ่มเรียน และอาจารย์แยกคอลัมน์ใน MariaDB
3. Admin เพิ่ม แก้รายละเอียด และลบห้องได้
4. รองรับรหัสห้องพิเศษ เช่น CL503
5. เพิ่มกลุ่ม "ห้องพิเศษ" โดยใช้ค่า Floor = 0
6. Excel จะนำเข้าเฉพาะห้องที่มีอยู่ในเมนูจัดการห้อง
7. ป้องกันการลบห้องที่ยังมีแอร์หรือตารางเรียนผูกอยู่

ติดตั้งบนโปรเจกต์เดิม
----------------------------------------
1. นำไฟล์ทั้งหมดในชุดนี้ไปทับโปรเจกต์ cpe_air_remote เดิม

2. เปิด PowerShell ที่โฟลเดอร์ backend แล้วรัน:

   npm install
   npm run db:migrate:rooms
   npm test
   npm run dev

   คำสั่ง db:migrate:rooms จะ:
   - สร้างตาราง rooms
   - เพิ่มห้องมาตรฐาน 16101–16307
   - เพิ่มห้องพิเศษ CL503
   - ขยายรหัสห้องเป็น VARCHAR(20)
   - เพิ่มคอลัมน์ section_name และ instructor
   - รักษาข้อมูลตารางเรียนและแอร์เดิมไว้

3. เปิดแอป:

   flutter clean
   flutter pub get
   flutter test
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

การใช้งาน
----------------------------------------
จัดการห้อง:
Admin > ควบคุม > ไอคอนจัดการห้องมุมขวาบน

เพิ่มห้องพิเศษ CL503:
- Room code: CL503
- Floor: 0
- Display order: 503
- Room type: Special Computer Laboratory

นำเข้า Excel:
Admin > ตารางเวลา > จัดการตารางเรียน > อัปโหลด Excel

หากชื่อชีตใน Excel ยังไม่มีในระบบ ระบบจะข้ามชีตนั้นและแจ้งให้ Admin
เพิ่มห้องก่อน จากนั้นจึงเลือกไฟล์ Excel เพื่อนำเข้าใหม่

หมายเหตุเกี่ยวกับ ESP32
----------------------------------------
หากต้องการติดตั้ง ESP32 ในห้องพิเศษ เช่น CL503 ต้องแฟลชเฟิร์มแวร์ใน
firmware/rmutt_esp32_air/rmutt_esp32_air.ino ของชุด v1.8.0 เพื่อให้บอร์ด
ยอมรับรหัสห้องแบบตัวอักษรได้ บอร์ดของห้องเลขเดิมยังใช้งานต่อได้ตามปกติ
