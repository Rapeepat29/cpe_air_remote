============================================================

RMUTT Save Energy - แก้เพิ่ม ESP32 ตัวที่ 2 ไม่ขึ้นหน้าตั้งค่า
============================================================

สาเหตุที่ยืนยันจาก Serial Monitor
---------------------------------
- ESP32 แสดง BLE app connected ได้ แปลว่าบอร์ดและชื่อ RMUTT-AC-* ทำงาน
- รอบแรกหลุดหลังประมาณ 15 วินาที ตรงกับ timeout เดิมของแอป
- แอปเดิมซ่อนข้อความผิดพลาดเมื่อยังอ่าน Device ID ไม่สำเร็จ จึงเห็นเพียง
  วงกลมเลือกอุปกรณ์ แต่ไม่มีฟอร์มหรือข้อความแจ้งเตือน

สิ่งที่แก้
----------
- แอปรอ connectionState จริงบน Windows และลองค้นหา GATT Service สูงสุด 3 ครั้ง
- หยุดสแกนก่อนเชื่อมต่อทุกครั้ง
- แสดงสถานะกำลังเชื่อมต่อ ข้อผิดพลาด และปุ่มลองเชื่อมต่ออีกครั้ง
- เมื่อยืนยันบอร์ดสำเร็จ แอปเลื่อนไปยังฟอร์มตั้งค่าให้อัตโนมัติ
- Firmware 1.6.0 ลดขนาด Identity packet แรก และแยกค่าตั้งเดิมไป UUID ใหม่
- ยังใช้ Device ID จาก eFuse MAC จึงไม่ซ้ำกันระหว่าง ESP32 แต่ละตัว
- Backend ยังตรวจ Device ID และห้อง + หมายเลขแอร์ซ้ำเหมือนเดิม

วิธีติดตั้ง
-----------
1. แตก ZIP แล้วนำโฟลเดอร์ cpe_air_remote ไปใช้แทนชุดเดิม
2. เปิดไฟล์ firmware/rmutt_esp32_air/rmutt_esp32_air.ino
3. เลือกบอร์ดและ COM Port ของ ESP32 ตัวที่ 2 แล้วอัปโหลด Firmware 1.6.0
4. กด EN/RESET หนึ่งครั้ง โดยไม่กด BOOT ค้าง
5. ปิดแอป Flutter เดิมทั้งหมด แล้วเปิด PowerShell ใน cpe_air_remote
6. รันคำสั่ง:

   flutter clean
   flutter pub get
   flutter test
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

7. เข้า ห้อง 16101 > เพิ่มแอร์ > ค้นหาบลูทูธ
8. เลือก RMUTT-AC-705F1971FE68 แล้วรอให้ขึ้น Device ID และฟอร์ม
9. เลือกหมายเลขแอร์ที่ยังไม่ถูกใช้ เช่น เครื่องที่ 2 แล้วบันทึก
