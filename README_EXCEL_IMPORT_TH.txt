============================================================

RMUTT Save Energy - Excel/CSV Timetable Import v1.8.5
=========================================================

สิ่งที่เพิ่ม
-----------
1. ผู้ดูแลระบบเลือกไฟล์ Excel .xlsx ต้นฉบับจากหน้าแอปได้โดยตรง
2. Backend อ่านทุกชีตของห้อง รวมถึงเซลล์ที่ถูกรวมใน Excel
3. แปลงเป็นข้อมูลหนึ่งแถวต่อหนึ่งคาบเรียน
4. แสดงจำนวนห้อง จำนวนคาบ ข้อสังเกต และตัวอย่างก่อนบันทึก
5. ดาวน์โหลด CSV แบบ UTF-8 ได้จากหน้าตัวอย่าง
6. ตรวจรหัสห้อง รูปแบบเวลา รายการซ้ำ และเวลาทับกัน
7. เมื่อยืนยัน ระบบแทนที่ตารางเดิมเฉพาะห้องที่พบในไฟล์
8. ทุกอย่างบันทึกใน Transaction หากเกิดข้อผิดพลาดจะไม่ลบตารางเดิมค้างไว้

ผลการทดสอบกับไฟล์ ตาราง.xlsx
-----------------------------
- ภาคเรียน: 1/2569
- ชีตทั้งหมด: 11
- ห้องที่นำเข้าได้: 11 ห้อง
- ตารางเรียนที่แปลงได้: 151 รายการ
- CL503 ถูกนำเข้าได้ แม้ลบห้องเดิมแล้ว เพราะระบบสร้างห้องหลัง Admin ยืนยัน
- ชื่ออาจารย์ถูกบันทึกและแสดงในหน้าตารางเรียน
- หากมีชีตห้องใหม่ ระบบจะแสดงห้องนั้นใน Preview ก่อนสร้าง

วิธีอัปเดต
----------
1. แตก ZIP แล้วนำโฟลเดอร์ cpe_air_remote ไปทับโปรเจกต์เดิม
   (ใช้ Flutter 3.32 ขึ้นไป; เครื่องปัจจุบันที่ใช้ Flutter 3.44.7 รองรับ)
2. เปิด PowerShell ในโฟลเดอร์ backend:

   npm install
   npm run db:migrate:rooms
   npm test
   npm run dev

3. เปิด PowerShell อีกหน้าที่โฟลเดอร์ cpe_air_remote:

   flutter clean
   flutter pub get
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

วิธีนำเข้าจากแอป
----------------
1. เข้าระบบด้วยบัญชี Admin
2. เปิดเมนู Schedule
3. กดปุ่มจัดการตารางเรียนมุมขวาบน
4. กดไอคอนอัปโหลดไฟล์
5. เลือกไฟล์ .xlsx หรือ .csv
6. ตรวจจำนวนห้อง รายการ ห้องใหม่ที่จะสร้าง และคำเตือน
7. หากต้องการ CSV ให้กด "บันทึก CSV"
8. กด "นำเข้าตารางเรียน" แล้วยืนยัน

ข้อควรรู้
--------
- รองรับไฟล์ไม่เกิน 8 MB
- การนำเข้าจะแทนที่เฉพาะห้องที่อยู่ในไฟล์ ห้องอื่นไม่เปลี่ยน
- หากชื่อชีตเป็นรหัสห้องใหม่ ระบบจะแสดงใน Preview และสร้างห้องหลัง Admin ยืนยัน
- ห้องรูปแบบ 16xxx จะคำนวณชั้นและลำดับจากรหัสห้องอัตโนมัติ
- ห้องพิเศษ เช่น CL503 จะถูกจัดไว้ในกลุ่มห้องพิเศษ (ชั้น 0)
- ไฟล์ CSV ที่บันทึกจากแอปเป็น UTF-8 และนำกลับเข้าแอปได้
- ต้องรัน migration ฐานข้อมูลหนึ่งครั้ง
- แฟลช ESP32 v1.8.0 เฉพาะบอร์ดที่จะใช้รหัสห้องพิเศษแบบตัวอักษร

วิธีแปลงผ่านคำสั่ง (สำรอง)
--------------------------
หากต้องการแปลง Excel เป็น CSV โดยไม่เปิดแอป:

   cd backend
   npm run schedules:convert -- "C:\path\ตาราง.xlsx" "C:\path\ตาราง.csv"
