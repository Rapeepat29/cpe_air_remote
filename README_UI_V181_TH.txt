RMUTT Save Energy - อัปเดตหน้าควบคุม v1.8.1
================================================

สิ่งที่เปลี่ยน
--------------
1. ย้ายปุ่มจัดการห้องเป็นปุ่มรูปเฟืองที่มุมขวาบน
2. แยกพื้นที่หัวข้อกับปุ่มอย่างชัดเจน ข้อความจึงไม่ถูกปุ่มทับ
3. ปรับตัวเลือกชั้นให้แบ่งความกว้างเท่ากันและเลื่อนได้เมื่อพื้นที่ไม่พอ
4. เพิ่มหัวข้อชั้นและจำนวนห้องที่กำลังแสดง
5. ปรับการ์ดห้อง ไอคอน สถานะ และระยะห่างให้อ่านง่ายขึ้น
6. รองรับทั้งธีมสว่าง ธีมมืด ภาษาไทย และภาษาอังกฤษ

ฟังก์ชันที่ยังอยู่ครบ
--------------------
- Admin เพิ่ม แก้ไข และลบห้อง
- ห้องพิเศษ เช่น CL503
- แสดงชื่ออาจารย์และนำเข้าตารางเรียนจาก Excel/CSV
- เพิ่มและตั้งค่า ESP32 ผ่าน Bluetooth
- ควบคุมแอร์ผ่าน MQTT
- ข้อมูลแอร์ไม่หายเมื่อเปลี่ยนธีมหรือภาษา

วิธีติดตั้ง
----------
นำโฟลเดอร์ lib และ test ไปทับโปรเจกต์เดิม หรือใช้ทั้งโฟลเดอร์
cpe_air_remote ใน ZIP นี้แทนชุด v1.8.0

จากนั้นรัน:

flutter clean
flutter pub get
flutter test
flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

ไม่ต้องแก้ฐานข้อมูล ไม่ต้องรัน migration ซ้ำ และไม่ต้องแฟลช ESP32 ใหม่
