## 5. MQTT (🪟 ผ่าน container บนเครื่อง)

แทน `<u>` `<p>` ด้วยค่าใน `mqtt\.env`

```powershell
# ฟังทุกข้อความ
docker exec rmutt-mosquitto mosquitto_sub -h 127.0.0.1 -p 1883 -u <u> -P <p> -v -t 'rmutt/#'

# ส่งข้อความ
docker exec rmutt-mosquitto mosquitto_pub -h 127.0.0.1 -p 1883 -u <u> -P <p> -t 'rmutt/ac/test' -m '{"hello":1}'

# ล้าง retained message ของ topic
docker exec rmutt-mosquitto mosquitto_pub -h 127.0.0.1 -p 1883 -u <u> -P <p> -r -n -t '<topic>'

# log ของ Broker
Get-Content mqtt\log\mosquitto.log -Tail 50
Get-Content mqtt\log\mosquitto.log -Tail 20 -Wait
Select-String -Path mqtt\log\mosquitto.log -Pattern 'not authorised' | Select-Object -Last 10
```

ตัวเลือก: `-t` topic · `-m` ข้อความ · `-v` แสดง topic · `-q 1` QoS · `-r` retain · `-n` ข้อความว่าง · `-C 1` รับ 1 แล้วจบ · `-W 8` รอ 8 วินาที

## 6. MariaDB / SQL

```powershell
# เข้า client บนเครื่อง
docker exec -it mariadb mariadb -uroot -p rmutt_save_energy

# สำรอง / กู้ (บนเครื่อง)
docker exec mariadb mariadb-dump -uroot -p<รหัส> --single-transaction rmutt_save_energy > backup.sql
Get-Content backup.sql -Raw | docker exec -i mariadb mariadb -uroot -p<รหัส> rmutt_save_energy
```

```sql
SHOW DATABASES;  USE rmutt_save_energy;  SHOW TABLES;
DESCRIBE air_conditioners;
SELECT * FROM rooms WHERE floor_number = 3 ORDER BY room_index;
SELECT room_number, SUM(consumption_kwh) FROM energy_hourly GROUP BY room_number;
SELECT a.name, r.floor_number FROM air_conditioners a JOIN rooms r ON r.room_number = a.room_number;
SELECT device_id, is_online, last_seen_at FROM air_conditioners;
SELECT room_number, is_occupied, radar_available FROM occupancy_sensors;
SELECT kind, room_number, status, created_at FROM system_alerts ORDER BY created_at DESC LIMIT 20;
SELECT * FROM system_settings;
UPDATE users SET is_active = 1 WHERE username = 'admin';
```

## 12. Git (แนะนำให้เริ่มใช้แทนไฟล์ `.bak`)

```powershell
git init                          # เริ่มเก็บประวัติในโฟลเดอร์นี้ (ครั้งเดียว)
git status                        # ไฟล์ไหนเปลี่ยน
git add .                         # เตรียมบันทึกทุกไฟล์ที่เปลี่ยน (.gitignore กันไฟล์ลับให้)
git commit -m "อธิบายสิ่งที่แก้"     # บันทึก
git log --oneline                 # ประวัติ
git diff                          # ดูว่าแก้อะไรไป (ก่อน add)
git restore <file>                # ยกเลิกการแก้ไฟล์นั้น
git switch -c feature/xxx         # แตกกิ่งใหม่ไปทดลอง
```

> ⚠️ ก่อน `git add .` ครั้งแรก ตรวจด้วย `git status` ว่าไม่มี `.env`, `passwords`, `key.properties`, `*.jks` หลุดเข้ามา
