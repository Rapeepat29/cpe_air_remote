## ส่วน A · ครั้งแรก

ทุกคำสั่งพิมพ์ใน PowerShell เริ่มจากโฟลเดอร์หลัก

```powershell

```

### A1. เปิด Docker Desktop
เปิดโปรแกรม รอจนขึ้น **Engine running** แล้วตรวจ

```powershell
docker info
```

### A2. สร้าง MariaDB (ถ้ายังไม่มี)

```powershell
docker ps -a --filter name=mariadb
```

ถ้าไม่มีแถวไหนขึ้นมา ให้สร้าง (เปลี่ยน `รหัสของคุณ`)

```powershell
docker run -d --name mariadb --restart unless-stopped `
  -e MARIADB_ROOT_PASSWORD=รหัสของคุณ `
  -e MARIADB_DATABASE=rmutt_save_energy `
  -e TZ=Asia/Bangkok `
  -p 3306:3306 -v rmutt-mariadb-data:/var/lib/mysql mariadb:11
```

### A3. ตั้งค่า MQTT Broker

```powershell
cd mqtt
.\setup_mqtt.ps1
cd ..
```

สคริปต์ทำให้
1. หา LAN IP
2. สุ่มรหัส MQTT → เขียน `mqtt\.env` และ `mqtt\config\passwords` (hash)
3. เขียน `mqtt\config\acl`
4. สร้าง `backend\.env` จาก `.env.example` (ถ้ายังไม่มี) แล้วใส่ค่า `MQTT_*`
5. เปิด Mosquitto (`docker compose up -d`) และทดสอบ pub/sub

ต้องจบด้วย `ตั้งค่า MQTT สำเร็จ`
ถ้า IP ที่เลือกไม่ตรงกับ `ipconfig` (เช่นมีหลายการ์ด หรือมี VPN)

```powershell
.\mqtt\setup_mqtt.ps1 -BrokerHost 192.168.1.10
```

### A4. แก้ `backend\.env`

```powershell
notepad backend\.env
```

แก้อย่างน้อยค่าเหล่านี้

```env

# รหัสเดียวกับที่ตั้งในขั้น A2

# ห้ามซ้ำกับ JWT_SECRET

# console = OTP แสดงในหน้าต่าง Backend ไม่ต้องตั้งอีเมล
```

สุ่มค่า (รันสองครั้ง คัดลอกไปใส่คนละบรรทัด)

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

**อย่าแก้** บรรทัด `MQTT_*` (สคริปต์ใส่ให้แล้ว)

> ⚠️ ในไฟล์ `.env` ให้เขียนคอมเมนต์ `#` **แยกบรรทัด** อย่าเขียนต่อท้ายค่า
> และไม่ต้องใส่ `<` `>` รอบค่าจริง

### A8. ล็อกอินและลองใช้
1. ล็อกอินด้วย `admin` / รหัสจาก `SEED_ADMIN_PASSWORD`
2. แท็บ **ควบคุม** → เห็นห้องตัวอย่าง 16101… (ยังไม่มีแอร์)
3. ลองเพิ่ม/แก้คาบเรียน ลองนำเข้าไฟล์ `examples\rmutt_class_schedules_1-2569.csv`
4. ลองลืมรหัสผ่าน → ดู OTP ในหน้าต่าง Backend

### A9. (ถ้ามีบอร์ด) เพิ่มแอร์ตัวแรก
1. อัปโหลด `firmware\rmutt_esp32_air\rmutt_esp32_air.ino` ลงบอร์ด (บท 11 ส่วนที่ 4)
2. Serial Monitor ต้องขึ้น `Mode: BLE recovery - No saved configuration`
3. **แอปต้องรันบนเครื่องที่มี Bluetooth** (โน้ตบุ๊ก Windows หรือมือถือ Android)
4. แอป → เข้าห้อง → **เพิ่มแอร์ผ่าน Bluetooth** → เลือก `RMUTT-AC-...`
5. เลือก Wi-Fi ที่บอร์ดสแกนเจอ ใส่รหัส Wi-Fi เลือกหมายเลขแอร์และยี่ห้อ → บันทึก
6. Serial Monitor: `Wi-Fi connected, IP: ...` → `Connecting MQTT: 192.168.1.10:1883` → เชื่อมต่อสำเร็จ
7. ในแอป แอร์ขึ้นออนไลน์ภายใน ~10 วินาที → ลองกดสั่ง → Serial ขึ้น `IR sent: ...`

ถ้าจะทดสอบกับมือถือ Android กับ Backend ในเครื่อง ดูบท 09 ส่วนที่ 5
(`--dart-define=API_BASE_URL=http://<LAN IP>:3000/api`, cleartext, firewall 3000)

### A10. (ถ้ามีบอร์ดตรวจคน)

## ส่วน B · ทุกวัน

```powershell
# 1. เปิด Docker Desktop (รอ Engine running)
# 2. เปิด PowerShell ที่โฟลเดอร์หลัก
cd "$HOME\Downloads\rmutt_save_energy_complete_mqtt\cpe_air_remote"

```

จบ

### ตัวเลือกของ `run_all.ps1`

| คำสั่ง | ใช้เมื่อ |
|---|---|
| `.\run_all.ps1` | ปกติ: DB + migrate + MQTT + Backend + แอป |
| `.\run_all.ps1 -SkipFlutter` | อยากเปิดแค่ฝั่งเซิร์ฟเวอร์ (เช่นจะใช้เว็บหรือมือถือแทน) |
| `.\run_all.ps1 -BrokerHost 192.168.1.153` | บังคับ LAN IP (มีหลายการ์ดเครือข่าย/VPN) |
| `.\run_all.ps1 -InitDb` | สร้างตารางครั้งแรก (รัน `db:init` ด้วย) |
| `.\run_all.ps1 -Server` | **ไม่เปิดอะไรในเครื่อง** ตรวจเซิร์ฟเวอร์จริงแล้วเปิดแอปชี้ไปที่นั่น |
| `.\run_all.ps1 -Server -SkipFlutter` | แค่ตรวจว่าเซิร์ฟเวอร์จริงปกติ |

### ถ้าเห็นข้อความนี้

```text
ค่าเดิมคือ mqtt://192.168.1.10:1883 - IP เปลี่ยนแล้ว ต้อง provision ESP32 ผ่าน Bluetooth ใหม่
```

แปลว่าวันนี้คอมได้ IP ใหม่ บอร์ดที่เคยตั้งค่าไว้ยังจำ IP เก่า มี 2 ทาง
1. **แนะนำ**: ตั้ง IP ของคอมให้คงที่ (DHCP reservation ที่เราเตอร์ หรือ Static IP ใน Windows)
   แล้วตั้งค่าบอร์ดใหม่ครั้งเดียว
2. ตั้งค่าบอร์ดใหม่ทุกครั้งที่ IP เปลี่ยน (BOOT + EN → แอป → ตั้งค่าใหม่ผ่านบลูทูธ)

## ส่วน E · สคริปต์ตรวจสุขภาพ

```powershell
.\check_system.ps1        # 3 ขั้น: Mosquitto healthy + pub/sub, Backend health, Backend↔MQTT
.\diagnose.ps1            # 7 ขั้น (ละเอียดกว่า ใช้ตอนมีปัญหา)
.\diagnose.ps1 -ListenSeconds 60   # ดักฟัง MQTT นานขึ้น
```

`diagnose.ps1` ตรวจ
1. container ที่ชื่อมี `rmutt`
2. LAN IP ตอนนี้ เทียบกับ `MQTT_URL` ใน `backend\.env`
3. `/api/health`
4. อุปกรณ์ในฐานข้อมูล
5. Windows Firewall พอร์ต 1883
6. log ของ Mosquitto 40 บรรทัดล่าสุด
7. ดักฟัง `rmutt/#` 20 วินาที (เห็นข้อความจากบอร์ดจริงไหม)
