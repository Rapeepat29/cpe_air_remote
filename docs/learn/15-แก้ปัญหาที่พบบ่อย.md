## 5. MQTT (Backend ↔ Broker ↔ บอร์ด)

| อาการ | ตรวจ | แก้ |
|---|---|---|
| `Backend ยังไม่เชื่อม MQTT: ...` | `docker ps` เห็น `rmutt-mosquitto` healthy ไหม, `MQTT_URL` ใน `backend\.env` | `.\mqtt\start_mqtt.ps1`, รัน `run_all.ps1` ให้เขียน `MQTT_URL` ใหม่ |
| `connack ... Not authorized` / `Bad username or password` | `MQTT_USERNAME/PASSWORD` ใน `backend\.env` ตรงกับ `mqtt\.env` ไหม | `run_all.ps1` คัดลอกให้ตรงกัน |
| สั่งแอร์ได้ **503** "Backend ยังไม่เชื่อมต่อ MQTT Broker" | `/api/health` | แก้ให้ `mqtt.connected: true` |
| บอร์ด Serial ขึ้น `MQTT connected` แต่ **แอปขึ้น "เซ็นเซอร์ไม่พร้อมใช้งาน"/ข้อมูลไม่มา** | `mqtt\log\mosquitto.log` มี `not authorised` ไหม | ACL ขาด `rmutt/occupancy/#` → รัน `run_all.ps1` (ซ่อมให้) หรือแก้ `mqtt\config\acl` แล้ว `docker compose restart broker` |
| บอร์ด `MQTT connection failed, state: -2` | บรรทัด `Connecting MQTT: <IP>:1883` ตรงกับ `ipconfig` ไหม, firewall | IP เปลี่ยน → ตั้งค่าบอร์ดใหม่; firewall → หัวข้อ 9 |
| บอร์ด `state: 4` | รหัส MQTT เปลี่ยนหลังตั้งค่าบอร์ด (รัน setup_mqtt.ps1 ใหม่) | ตั้งค่าบอร์ดใหม่ผ่าน Bluetooth |
| บอร์ด `state: 5` | ACL / บัญชี dynsec | ตรวจ ACL, หรือถอดแล้วเพิ่มบอร์ดใหม่ (dynsec) |
| บอร์ด (เซิร์ฟเวอร์จริง) `NTP sync failed; TLS certificate check will fail` | Wi-Fi ไม่ออกอินเทอร์เน็ต/บล็อก NTP | ให้ฝ่ายไอทีเปิด NTP (UDP 123) |
| บอร์ด (จริง) ต่อ 8883 ไม่ได้ทั้งตึกพร้อมกัน | ใบรับรองหมดอายุ/ไม่ได้ sync | `sudo bash sync-mqtt-cert.sh`, ตรวจ cron |

ดักดูข้อความจริง

```powershell
.\diagnose.ps1 -ListenSeconds 30
```

## 8. บอร์ด / ฮาร์ดแวร์

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| Arduino ไม่เห็น COM port | ไดรเวอร์ CP210x/CH340, สายชาร์จอย่างเดียว | ลงไดรเวอร์, เปลี่ยนสาย |
| `Failed to connect to ESP32: Timed out` | บอร์ดไม่เข้าโหมดอัปโหลด | กด BOOT ค้างตอนขึ้น `Connecting....` |
| Serial เป็นขยะ | baud ไม่ตรง | ตั้ง 115200 |
| สั่งแอร์แล้ว Serial ขึ้น `IR sent` แต่แอร์เฉย | ยี่ห้อ (protocol) ไม่ตรง, IR ไม่เล็งตัวรับ, ไม่มีทรานซิสเตอร์ขับ | เปลี่ยน protocol ในการตั้งค่า, จัดตำแหน่ง, ตรวจวงจร |
| `IR protocol is not supported: XXX` | ชื่อยี่ห้อผิด | ใช้ชื่อตามรายการใน `docs/BLE_MQTT_PROTOCOL.md` |
| `pzemAvailable: false` | สาย PZEM ไม่ไขว้, ไม่มีไฟ 220V เข้า PZEM (PZEM ต้องมีไฟฝั่ง AC จึงตอบ) | ตรวจ TX→GPIO16, RX→GPIO18, GND; ให้ช่างตรวจฝั่ง AC |
| LD2410 `UART1 rx bytes ...: 0` | สาย/ไฟ | TX→GPIO32, RX→GPIO33, VCC 5V, GND ร่วม; ใช้ `ld2410_pinscan.ino` |
| LD2410 มีไบต์แต่ไม่มีเฟรม | baud ผิด | pinscan จะบอก baud ที่ถูก |
| ห้องว่างแต่ขึ้น "มีคน" | เกณฑ์ 25 ต่ำไปสำหรับห้องนั้น (พัดลม ม่านไหว) | ดู `[gates]` ใน Serial ปรับ `STATIC_ENERGY_THRESHOLD` |
| บอร์ดบูตไม่ขึ้นหลังต่อสายใหม่ | `GPIO12` ถูกดึง HIGH ตอนบูต | ย้ายสายออกจาก GPIO12 |
| อยากล้างบอร์ดให้เหมือนใหม่ | | อัปโหลด `firmware\reset\reset.ino` |

## 9. เครือข่าย / Firewall

มือถือหรือ ESP32 ต่อคอมไม่ได้ ทั้งที่ในเครื่องใช้ได้ → **Windows Firewall**

ตรวจ

```powershell
Test-NetConnection -ComputerName <LAN IP ของคอม> -Port 1883
Get-NetConnectionProfile            # NetworkCategory ควรเป็น Private
```

เปิดพอร์ต (PowerShell แบบ **Run as Administrator**)

```powershell
New-NetFirewallRule -DisplayName "RMUTT MQTT 1883" -Direction Inbound -Protocol TCP -LocalPort 1883 -Action Allow -Profile Private
New-NetFirewallRule -DisplayName "RMUTT API 3000"  -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

- `-Profile Private` = เปิดเฉพาะเครือข่ายที่ตั้งเป็น Private (บ้าน/แล็บ) ไม่เปิดใน Wi-Fi สาธารณะ
- ถ้า Wi-Fi ถูกตั้งเป็น Public: `Set-NetConnectionProfile -InterfaceAlias "Wi-Fi" -NetworkCategory Private`

ลบกฎ

```powershell
Remove-NetFirewallRule -DisplayName "RMUTT MQTT 1883"
```

ปัญหาอื่น
- Wi-Fi มหาวิทยาลัยบางวง **แยกอุปกรณ์ไม่ให้คุยกันเอง** (client isolation) → ESP32 ต่อคอมไม่ได้ทั้งที่อยู่ Wi-Fi เดียวกัน
  ใช้ hotspot/เราเตอร์ของตัวเองตอนพัฒนา หรือใช้เซิร์ฟเวอร์จริง
- มี VPN เปิดอยู่ → `Get-LanIPv4` อาจเลือกการ์ดผิด → ใช้ `-BrokerHost`

## 12. ถ้ายังไม่หาย — เก็บข้อมูลก่อนถามคนอื่น

1. ข้อความ error **ทั้งหมด** (คัดลอกเป็นข้อความ ไม่ใช่ภาพถ่ายหน้าจอ)
2. ผลของ `.\diagnose.ps1`
3. หน้าต่าง Backend 30 บรรทัดสุดท้าย
4. Serial Monitor ของบอร์ด (ถ้าเกี่ยว)
5. ทำอะไรไปก่อนหน้านั้น (แก้ไฟล์ไหน รันคำสั่งอะไร)

> ⚠️ ก่อนแชร์ ลบรหัสผ่าน / ค่าใน `.env` / token ออกก่อนเสมอ
