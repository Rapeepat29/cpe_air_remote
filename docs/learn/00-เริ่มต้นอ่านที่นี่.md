# 00 · เริ่มต้นอ่านที่นี่ — คู่มือเรียนรู้โปรเจกต์ RMUTT Save Energy ตั้งแต่ศูนย์

> คู่มือชุดนี้เขียนสำหรับคนที่ **ไม่เคยเขียนโปรแกรมมาก่อนเลย**
> อ่านจบแล้วควรจะ
> 1. เข้าใจว่าระบบนี้ทำอะไร ประกอบด้วยอะไร และแต่ละชิ้นคุยกันอย่างไร

> 3. รันระบบทั้งหมดบนเครื่องตัวเองได้
> 4. อ่านโค้ดแต่ละส่วนแล้วรู้ว่าบรรทัดนั้นทำอะไร
> 5. รู้ว่าคำสั่งแต่ละคำสั่งมีไว้ทำอะไร และแต่ละส่วนของคำสั่งแปลว่าอะไร
> 6. แก้ปัญหาเบื้องต้นเองได้ และนำขึ้นเซิร์ฟเวอร์จริงได้

## 3. วิธีอ่านสัญลักษณ์ในคู่มือ

### 3.1 กล่องคำสั่ง

````text
```powershell
cd backend
npm test
```
````

- `powershell` = พิมพ์ใน **PowerShell บน Windows**
- `bash` = พิมพ์บน **เซิร์ฟเวอร์ Linux** (หลัง `ssh` เข้าไปแล้ว) หรือใน Git Bash
- `sql` = พิมพ์ในโปรแกรมฐานข้อมูล เช่น HeidiSQL
- `text` = ไม่ใช่คำสั่ง เป็นผลลัพธ์หรือแผนภาพ

**พิมพ์ทีละบรรทัด แล้วกด Enter** ห้ามพิมพ์เครื่องหมาย `#` และข้อความหลังจากนั้น
เพราะนั่นคือ "คอมเมนต์" (คำอธิบาย) ไม่ใช่คำสั่ง

### 3.2 ค่าที่ต้องเปลี่ยนเอง

ถ้าเห็น `<อะไรบางอย่าง>` ในวงเล็บแหลม หมายถึง **ต้องแทนด้วยค่าจริงของคุณ**
และ **ไม่ต้องพิมพ์ `<` `>`**

```powershell
ssh <user>@<host>
# ของจริงจะเป็น เช่น
ssh rmutt@energy.eng.rmutt.ac.th
```

### 3.3 ตำแหน่งที่พิมพ์คำสั่ง

คำสั่งส่วนใหญ่ **ต้องพิมพ์ในโฟลเดอร์ที่ถูกต้อง** คู่มือจะบอกเสมอ เช่น

> 📁 พิมพ์ที่โฟลเดอร์ `cpe_air_remote\backend`

โฟลเดอร์หลักของโปรเจกต์บนเครื่องคุณคือ

```text
C:\Users\rapee\Downloads\rmutt_save_energy_complete_mqtt\cpe_air_remote
```

ในคู่มือจะเรียกสั้น ๆ ว่า **"โฟลเดอร์หลัก"** หรือ `cpe_air_remote`

### 3.4 กล่องเตือน

> ⚠️ **คำเตือน** — ทำผิดแล้วข้อมูลหายหรือระบบพัง

> 💡 **เคล็ดลับ** — ไม่จำเป็น แต่ช่วยให้ง่ายขึ้น

> 🧪 **ลองทำ** — แบบฝึกหัดสั้น ๆ ให้ลงมือเอง

## 5. ภาพรวมระบบแบบสั้นที่สุด (ก่อนเริ่มบท 01)

ระบบนี้ทำ 3 อย่างให้อาคาร 16 คณะวิศวกรรมศาสตร์ มทร.ธัญบุรี

1. **วัดไฟ** ของแอร์แต่ละเครื่อง (ใช้ PZEM-004T)
2. **รู้ว่ามีคนอยู่ในห้องไหม** (ใช้เรดาร์ HLK-LD2410)
3. **สั่งเปิด/ปิดแอร์** จากแอปหรืออัตโนมัติเมื่อห้องว่าง (ใช้ไฟ IR แบบรีโมต)

ชิ้นส่วนมี 6 ชิ้น

```text
 [แอปมือถือ Flutter]   [เว็บแอป]          ← คนใช้
         │                 │
         └──── HTTPS ──────┘
                  ▼
          [Backend Node.js]  ─── [ฐานข้อมูล MariaDB]   ← สมองกลาง + ความจำ
                  │
                MQTT
                  ▼
        [Mosquitto Broker]                              ← ไปรษณีย์ส่งข้อความ
           │            │
      [ESP32 แอร์]  [ESP32 ตรวจคน]                      ← มือและตาในห้อง
           │            │
         IR+PZEM      LD2410
           ▼
      เครื่องปรับอากาศ
```

บทต่อไปจะอธิบายทุกคำในภาพนี้ เริ่มจาก **บท 01 พื้นฐานคอมพิวเตอร์และเครือข่าย**
