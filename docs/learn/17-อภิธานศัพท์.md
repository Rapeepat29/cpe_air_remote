# 17 · อภิธานศัพท์ (Glossary)

> เรียงตามตัวอักษรภาษาอังกฤษ วงเล็บท้ายบอกบทที่อธิบายละเอียด

| คำ | ความหมาย |
|---|---|
| **ACL** (Access Control List) | รายการว่าใครทำอะไรได้ ใน Mosquitto คือไฟล์บอกว่าผู้ใช้ไหนอ่าน/เขียน topic ไหนได้ (06) |
| **Active-high** | อุปกรณ์ทำงานเมื่อขาเป็น HIGH (11) |
| **API** (Application Programming Interface) | "เมนู" ของสิ่งที่โปรแกรมอื่นขอได้ ในโปรเจกต์คือ URL ใต้ `/api/...` (08) |
| **APK** | ไฟล์ติดตั้งแอป Android (09) |
| **Argument / Parameter** | ค่าที่ส่งให้คำสั่งหรือฟังก์ชัน (03) |
| **Arrow function** | ฟังก์ชันแบบย่อ `(x) => x * 2` (08) |
| **async / await** | วิธีเขียนโค้ดที่ต้อง "รอ" (ฐานข้อมูล เครือข่าย) โดยไม่บล็อกงานอื่น (08) |
| **Authentication** | การยืนยันว่าเป็นใคร (ล็อกอิน) |
| **Authorization** | การตรวจว่ามีสิทธิ์ทำสิ่งนั้นไหม (admin/staff) |
| **Backend** | ส่วนเซิร์ฟเวอร์ที่ถือข้อมูลและตรรกะ (Node.js ในโปรเจกต์นี้) (08) |
| **Baud rate** | ความเร็ว UART หน่วยบิต/วินาที (11) |
| **bcrypt** | อัลกอริทึม hash รหัสผ่านแบบช้าโดยตั้งใจ (08) |
| **Bearer token** | รูปแบบการแนบ token ใน header `Authorization: Bearer ...` (01) |
| **BLE** (Bluetooth Low Energy) | Bluetooth แบบประหยัดพลังงาน ใช้ตั้งค่าบอร์ดครั้งแรก (11) |
| **Bind mount** | ผูกโฟลเดอร์จริงเข้ากับโฟลเดอร์ใน container (05) |
| **Broker** | ตัวกลางรับส่งข้อความ MQTT (Mosquitto) (06) |
| **Build** | แปลงโค้ดเป็นไฟล์ที่รันได้ (APK, .exe, Docker image) |
| **Bucket (ถัง)** | ช่วงเวลาที่รวมข้อมูลไว้ด้วยกัน ในโปรเจกต์คือ 1 ชั่วโมง (07, 12) |
| **CA** (Certificate Authority) | ผู้ออกใบรับรองที่ทุกเครื่องเชื่อถือ เช่น Let's Encrypt (01, 14) |
| **Caddy** | Web server ที่ทำ HTTPS อัตโนมัติ + reverse proxy (14) |
| **Callback** | ฟังก์ชันที่ส่งให้คนอื่นเรียกกลับเมื่อมีเหตุการณ์ เช่น `mqttCallback` (11) |
| **CASCADE / RESTRICT** | พฤติกรรม Foreign Key เมื่อแถวแม่ถูกแก้/ลบ (07) |
| **ChangeNotifier** | คลาส Flutter ที่แจ้งหน้าจอเมื่อข้อมูลเปลี่ยน (09) |
| **Characteristic** | ช่องข้อมูลหนึ่งช่องใน BLE GATT (11) |
| **CLI** (Command Line Interface) | โปรแกรมที่ใช้ด้วยการพิมพ์คำสั่ง (03) |
| **Client** | ฝ่ายที่ขอ (01) |
| **Column / Row** | คอลัมน์ / แถว ในตารางฐานข้อมูล (07) |
| **Commit** | ยืนยัน transaction (SQL) / บันทึกประวัติ (Git) |
| **Compile** | แปลงโค้ดเป็นภาษาเครื่อง (Arduino ✓, Flutter build) |
| **Connection pool** | กลุ่มการเชื่อมต่อฐานข้อมูลที่เปิดค้างไว้ใช้ซ้ำ (08) |
| **Container** | กล่องที่รันโปรแกรมแยกจากเครื่องจริง สร้างจาก image (05) |
| **Controller** | (ในแอปนี้) คลาสที่ถือ state และตรรกะของหน้าจอ (09) |
| **CORS** | กฎเบราว์เซอร์ที่ห้ามเว็บเรียก API ต่างโดเมนถ้าไม่ได้รับอนุญาต (10) |
| **cron** | ตัวตั้งเวลางานบน Linux (14) |
| **CSP** (Content-Security-Policy) | header บอกเบราว์เซอร์ว่าโหลดสคริปต์จากไหนได้บ้าง (10, 14) |
| **CSV** | ไฟล์ตารางแบบข้อความ คั่นด้วยจุลภาค |
| **Dart** | ภาษาที่ใช้เขียน Flutter (09) |
| **`--dart-define`** | ส่งค่าเข้าแอปตอน build เช่น `API_BASE_URL` (09) |
| **Database** | ฐานข้อมูล (07) |
| **DECIMAL** | ชนิดตัวเลขทศนิยมแม่นยำใน SQL (07) |
| **Dependency** | ไลบรารีที่โปรเจกต์ต้องใช้ (08, 09) |
| **Deploy** | นำระบบขึ้นเซิร์ฟเวอร์จริง (14) |
| **Device ID** | รหัสบอร์ดจาก MAC เช่น `ESP32-AABBCCDDEEFF`, `OCC32-...` (11) |
| **DevTools** | เครื่องมือนักพัฒนาในเบราว์เซอร์ กด F12 (10) |
| **DHCP** | ระบบแจก IP อัตโนมัติของเราเตอร์ (IP จึงเปลี่ยนได้) |
| **DNS** | ระบบแปลงชื่อโดเมนเป็น IP (01) |
| **Docker / Docker Compose** | ระบบรันโปรแกรมในกล่อง / ไฟล์รันหลายกล่องพร้อมกัน (05) |
| **Dockerfile** | สูตรสร้าง image (05) |
| **DOM** | โครงสร้าง HTML ในหน่วยความจำที่ JS แก้ได้ (10) |
| **Dynamic Security (dynsec)** | ปลั๊กอิน Mosquitto ที่ให้บอร์ดแต่ละตัวมีบัญชีของตัวเอง (06, 14) |
| **eFuse MAC** | หมายเลขประจำชิป ESP32 ที่เปลี่ยนไม่ได้ (11) |
| **Endpoint / Route** | URL + method หนึ่งอันของ API เช่น `GET /api/rooms` (08) |
| **Engineering mode** | โหมดของ LD2410 ที่ให้ค่ารายเกต (11) |
| **ENUM** | ชนิดข้อมูล SQL ที่เลือกได้เฉพาะค่าที่กำหนด (07) |
| **Environment variable / `.env`** | ค่าตั้งที่อยู่นอกโค้ด มักเป็นความลับ (01, 08) |
| **ES Module** | ระบบ `import`/`export` ของ JavaScript (08, 10) |
| **ESP32** | ไมโครคอนโทรลเลอร์ที่มี Wi-Fi + BLE (11) |
| **Express** | เฟรมเวิร์กทำ HTTP server บน Node.js (08) |
| **Factory reset** | ล้างค่าบอร์ดกลับเป็นเหมือนใหม่ (`reset.ino`) (11) |
| **fail2ban** | โปรแกรมบล็อก IP ที่เดารหัส SSH (14) |
| **Firewall** | ตัวกั้นว่าพอร์ตไหนเข้าได้ (15) |
| **Firmware** | โปรแกรมในบอร์ดอิเล็กทรอนิกส์ (11) |
| **Flash** | หน่วยความจำถาวรในบอร์ด / การเขียนโปรแกรมลงบอร์ด (11) |
| **Flutter** | เฟรมเวิร์กทำแอปหลายแพลตฟอร์ม (09) |
| **Foreign Key (FK)** | คอลัมน์ที่อ้างถึงแถวในตารางอื่น (07) |
| **Future** | ค่าที่จะได้ในอนาคต (Dart) = Promise (JS) (09) |
| **Gate** | ช่วงระยะของเรดาร์ LD2410 (0–8, ~0.75 m ต่อเกต) (11) |
| **GATT** | โครงสร้างข้อมูลของ BLE (Service/Characteristic) (11) |
| **Git** | ระบบเก็บประวัติโค้ด (16) |
| **GND** | กราวด์ จุดอ้างอิง 0V (11) |
| **GPIO** | ขาที่โปรแกรมควบคุมได้ของไมโครคอนโทรลเลอร์ (11) |
| **Hash** | การแปลงข้อมูลทางเดียว ย้อนกลับไม่ได้ (01, 08) |
| **Header (HTTP)** | ข้อมูลประกอบของคำขอ/คำตอบ เช่น `Authorization` (01) |
| **Healthcheck** | คำสั่งที่ Docker ใช้ตรวจว่ากล่อง "ใช้ได้จริง" (05) |
| **HMAC** | hash ที่ต้องใช้กุญแจลับ (pepper) ร่วมด้วย ใช้กับ OTP (08) |
| **Hot reload** | ใส่โค้ดใหม่เข้าแอป Flutter ที่รันอยู่ในวินาทีเดียว กด `r` (09) |
| **HTTP / HTTPS** | โปรโตคอลเว็บ / แบบเข้ารหัส (01) |
| **Hysteresis** | ใช้เกณฑ์ขึ้น/ลงคนละค่ากันสถานะกระเพื่อม (30W เปิด / 10W ปิด) (11) |
| **Idempotent** | ทำซ้ำกี่ครั้งผลเท่าเดิม (06) |
| **Image (Docker)** | แม่แบบของ container (05) |
| **Index** | สารบัญช่วยค้นเร็วในฐานข้อมูล (07) |
| **IP address** | ที่อยู่ของเครื่องในเครือข่าย (01) |
| **IR** (Infrared) | แสงอินฟราเรด ใช้ในรีโมตแอร์ (11) |
| **JOIN** | รวมข้อมูลหลายตารางใน SQL (07) |
| **JSON** | รูปแบบข้อมูลแบบข้อความที่ทุกส่วนใช้คุยกัน (01) |
| **JWT** (JSON Web Token) | token ที่มีข้อมูลและลายเซ็นในตัว (01, 08) |
| **Keystore (.jks)** | ไฟล์กุญแจเซ็น APK (09) |
| **kWh** | กิโลวัตต์-ชั่วโมง = 1 หน่วยไฟในบิล (11) |
| **LAN / LAN IP** | เครือข่ายภายใน / IP ภายในวง (01) |
| **LD2410** | โมดูลเรดาร์ 24 GHz ตรวจคน (11) |
| **Let's Encrypt** | CA ที่ออกใบรับรอง HTTPS ฟรี (14) |
| **Library / Package** | โค้ดสำเร็จรูปที่ดึงมาใช้ (npm, pub, Arduino) |
| **Localhost / 127.0.0.1** | เครื่องตัวเอง (01) |
| **localStorage** | ที่เก็บข้อมูลเล็ก ๆ ในเบราว์เซอร์ (10) |
| **LWT** (Last Will and Testament) | ข้อความที่ Broker ส่งแทนเมื่อ client หายไปไม่บอกลา (06) |
| **MariaDB** | ระบบฐานข้อมูล (สายเดียวกับ MySQL) (07) |
| **Middleware** | ฟังก์ชันที่คำขอผ่านก่อนถึง handler (08) |
| **Migration** | สคริปต์อัปเกรดโครงสร้างฐานข้อมูลโดยไม่ลบข้อมูล (07) |
| **millis()** | เวลามิลลิวินาทีตั้งแต่บอร์ดเปิด ใช้ทำงานแบบไม่บล็อก (11) |
| **Model** | คลาสที่แทนรูปร่างข้อมูล เช่น `Room` (09) |
| **Mosquitto** | MQTT Broker ที่ใช้ในโปรเจกต์ (06) |
| **MQTT / MQTTS** | โปรโตคอล publish/subscribe สำหรับ IoT / แบบเข้ารหัส (06) |
| **Node.js** | ตัวรัน JavaScript นอกเบราว์เซอร์ (08) |
| **npm** | ตัวจัดการไลบรารีของ Node.js (08) |
| **NTP** | โปรโตคอลตั้งเวลาทางเครือข่าย (11, 14) |
| **Null safety** | ระบบบังคับประกาศว่าค่าไหนว่างได้ (Dart `?`) (09) |
| **NVS** | ความจำถาวรในบอร์ด ESP32 (Preferences) (11) |
| **OTA** (Over-The-Air) | อัปเดตเฟิร์มแวร์ผ่าน Wi-Fi (11) |
| **OTP** (One-Time Password) | รหัสใช้ครั้งเดียว 6 หลักทางอีเมล (08) |
| **Parameter binding (`?`)** | ส่งค่าแยกจากคำสั่ง SQL กัน SQL injection (07) |
| **Partition** | การแบ่งพื้นที่ flash ของบอร์ด (11) |
| **PATH** | รายการโฟลเดอร์ที่ Windows ใช้หาโปรแกรม (03) |
| **Payload** | เนื้อหาของข้อความ (MQTT) หรือข้อมูลใน token |
| **Pepper** | ค่าลับที่ผสมตอน hash (OTP_PEPPER) (08) |
| **Pipeline `|`** | ส่งผลลัพธ์ของคำสั่งหนึ่งให้อีกคำสั่ง (03) |
| **Polling** | ถามซ้ำ ๆ เป็นรอบ (แอป/เว็บดึงข้อมูลทุก 10 วินาที) (06, 10) |
| **Port** | หมายเลขช่องของโปรแกรมบนเครื่อง (01) |
| **Port mapping** | ต่อพอร์ตเครื่องจริงเข้ากล่อง Docker (05) |
| **PowerShell** | Shell ของ Windows (03) |
| **Primary Key (PK)** | คอลัมน์ที่ระบุแถวไม่ซ้ำ (07) |
| **Process / PID** | โปรแกรมที่กำลังรัน / หมายเลขของมัน (01, 03) |
| **Protocol** | กติกาการสื่อสาร (01) |
| **Provisioning** | การตั้งค่าบอร์ดใหม่ให้เข้าระบบ + ยืนยันตัวตน (12) |
| **Publish / Subscribe** | ส่งข้อความ / สมัครรับข้อความของ topic (06) |
| **Pull-up** | ตัวต้านทานดึงขาไว้ที่ HIGH (11) |
| **PZEM-004T** | โมดูลวัดไฟ AC (V, A, W, kWh, Hz, PF) (11) |
| **QoS** | ระดับการรับประกันการส่ง MQTT (06) |
| **Rate limit** | จำกัดจำนวนครั้งที่เรียกได้ต่อช่วงเวลา (08) |
| **Registry (Docker Hub)** | คลัง image ออนไลน์ (05) |
| **Repository** | (ในแอปนี้) interface ที่บอกว่าดึงข้อมูลอะไรได้ / (Git) คลังโค้ด (09) |
| **Request / Response** | คำขอ / คำตอบ (01) |
| **Retain** | ให้ Broker จำข้อความล่าสุดของ topic (06) |
| **Reverse proxy** | ตัวกลางรับคำขอแทนเซิร์ฟเวอร์ข้างหลัง (Caddy) (14) |
| **Rollback** | ยกเลิก transaction (07) |
| **Root CA** | ใบรับรองต้นทางที่ฝังในเฟิร์มแวร์ (11) |
| **Router (Express)** | กลุ่มเส้นทาง API (08) |
| **Schema** | โครงสร้างตารางทั้งหมด (`schema.sql`) (07) |
| **Script** | ไฟล์รวมคำสั่งให้รันอัตโนมัติ (`.ps1`, `.sh`) (03) |
| **SDK** | ชุดเครื่องมือพัฒนา (Flutter SDK, Android SDK) (04) |
| **Secure Storage** | ที่เก็บลับของระบบปฏิบัติการ (แอปเก็บ token) (09) |
| **Serial Monitor** | หน้าต่างดูข้อความจากบอร์ด (11) |
| **Server** | ฝ่ายที่ให้บริการ / เครื่องที่รันบริการ (01) |
| **Service (Backend)** | โมดูลที่ทำงานเบื้องหลัง/คุยกับโลกภายนอก (08) |
| **Service (Compose)** | ชื่อกล่องหนึ่งในไฟล์ `docker-compose.yml` (05) |
| **setState** | สั่ง Flutter วาดหน้าจอใหม่เมื่อ state เปลี่ยน (09) |
| **Shell** | โปรแกรมรับคำสั่งพิมพ์ (03) |
| **SMTP** | โปรโตคอลส่งอีเมล (08) |
| **SQL** | ภาษาสั่งงานฐานข้อมูล (07) |
| **SQL injection** | การโจมตีด้วยการแทรกคำสั่ง SQL ในข้อมูลผู้ใช้ (07) |
| **SSH / SCP** | เข้าเครื่องระยะไกลแบบเข้ารหัส / คัดลอกไฟล์ผ่าน SSH (14) |
| **SSH tunnel** | ส่งพอร์ตผ่าน SSH (`-L`) (14) |
| **Stack trace** | รายการฟังก์ชันที่ถูกเรียกตอนเกิด error (08) |
| **State** | ข้อมูลที่เปลี่ยนได้ระหว่างใช้งาน (09) |
| **State machine** | ระบบที่อยู่ได้ทีละสถานะและมีกติกาเปลี่ยนสถานะ (auto-off) (12) |
| **Stateless / Stateful widget** | widget ที่ไม่มี / มี state ของตัวเอง (09) |
| **Status code** | ตัวเลขผลลัพธ์ HTTP (200, 401, 404, 500…) (01) |
| **Swap** | หน่วยความจำสำรองบนดิสก์ (14) |
| **Switch parameter** | พารามิเตอร์เปิด/ปิดของ PowerShell เช่น `-SkipFlutter` (03) |
| **Tag (Docker)** | รุ่นของ image หลัง `:` (05) |
| **Template literal** | ข้อความแทนค่าได้ `` `a ${x}` `` (08) |
| **Test (unit / widget)** | โค้ดตรวจโค้ด (08, 09) |
| **Timing attack** | การเดาข้อมูลจากเวลาที่ระบบใช้ตอบ (08) |
| **TLS** | ชั้นเข้ารหัสของ HTTPS/MQTTS (01) |
| **Token** | บัตรผ่านหลังล็อกอิน (01) |
| **token_version** | ตัวเลขที่ใช้เพิกถอน token เก่าทั้งหมดของผู้ใช้ (08) |
| **Topic** | ชื่อช่องข้อความ MQTT (06) |
| **Transaction** | กลุ่มคำสั่ง SQL ที่ต้องสำเร็จทั้งหมดหรือไม่เลย (07) |
| **UART** | การสื่อสารอนุกรมผ่านสาย TX/RX (11) |
| **UUID** | รหัสสุ่มไม่ซ้ำ 36 ตัว (07) |
| **Volume** | ที่เก็บข้อมูลของ Docker ที่อยู่รอดเมื่อลบกล่อง (05) |
| **VPS** | เซิร์ฟเวอร์เสมือนที่เช่า (14) |
| **Widget** | ชิ้นส่วนหน้าจอ Flutter (09) |
| **Wildcard (`+`, `#`)** | สัญลักษณ์แทน topic หลายตัวตอน subscribe (06) |
| **WSL 2** | Linux ใน Windows ที่ Docker Desktop ใช้ (04) |
| **XSS** | การฝังสคริปต์แปลกปลอมในหน้าเว็บ (10) |
| **YAML** | ภาษาไฟล์ตั้งค่าที่ใช้ย่อหน้า (`docker-compose.yml`, `pubspec.yaml`) (05) |
