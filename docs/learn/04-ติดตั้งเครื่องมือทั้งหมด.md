# 04 · ติดตั้งเครื่องมือทั้งหมด

> บทนี้บอกว่าต้องติดตั้งอะไร **ทำไมต้องใช้** ติดตั้งอย่างไร และ **ตรวจอย่างไรว่าติดตั้งสำเร็จ**
> ไม่ต้องติดตั้งทุกตัวในวันเดียว ดูคอลัมน์ "ต้องใช้เมื่อ" แล้วติดตั้งตามบทที่กำลังเรียน

## 1. VS Code — โปรแกรมแก้ไขโค้ด

**ทำไมต้องใช้:** Notepad แก้โค้ดได้ แต่ไม่มีสีแยกไวยากรณ์ ไม่มีการเติมคำ หาไฟล์ยาก

```powershell
winget install -e --id Microsoft.VisualStudioCode
```

หรือดาวน์โหลดที่ <https://code.visualstudio.com>
ตอนติดตั้ง ติ๊ก **"Add to PATH"** และ **"Add 'Open with Code' action"**

### Extension ที่แนะนำ (กด `Ctrl+Shift+X` แล้วค้นชื่อ)

| Extension | ใช้กับ |
|---|---|
| Flutter (Dart-Code) | แอป Flutter (ติดตั้ง Dart ให้ด้วย) |
| ESLint | JavaScript ของ Backend |
| PowerShell | สคริปต์ `.ps1` |
| Docker | ดู container |
| Thai Language Pack (ถ้าต้องการ) | เมนูภาษาไทย |

### ตรวจ

```powershell
code --version
```

เปิดโปรเจกต์: ไปที่โฟลเดอร์หลักแล้วพิมพ์ `code .`

## 3. Node.js — ตัวรัน JavaScript นอกเบราว์เซอร์

**ทำไมต้องใช้:** Backend เขียนด้วย JavaScript และ `package.json` กำหนดไว้ว่า
`"engines": { "node": ">=20" }` (บนเซิร์ฟเวอร์ใช้ `node:22-alpine`)

ติดตั้งรุ่น **LTS** (Long Term Support) รุ่น 22 แนะนำที่สุดเพื่อให้ตรงกับเซิร์ฟเวอร์

```powershell
winget install -e --id OpenJS.NodeJS.LTS
```

หรือ <https://nodejs.org> เลือก LTS

Node.js มาพร้อม **npm** (Node Package Manager) = ตัวดาวน์โหลดไลบรารี

### ตรวจ

```powershell
node --version     # ต้องได้ v20.x.x ขึ้นไป เช่น v22.11.0
npm --version
```

### ทดลองรัน JavaScript บรรทัดเดียว

```powershell
node -e "console.log(1 + 2)"
```

- `node` = โปรแกรม
- `-e` = "evaluate" รันโค้ดที่ตามมาเลย ไม่ต้องมีไฟล์
- ผลลัพธ์: `3`

คำสั่งนี้ถูกใช้ในโปรเจกต์เพื่อ **สุ่มรหัสลับ**

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

- `require('crypto')` = โหลดโมดูลเข้ารหัสของ Node
- `randomBytes(48)` = สุ่มข้อมูล 48 ไบต์แบบปลอดภัยทางการเข้ารหัส
- `.toString('hex')` = แปลงเป็นตัวอักษร 0–9 a–f (ได้ 96 ตัว)

## 4. Docker Desktop — ตัวรันโปรแกรมในกล่อง

**ทำไมต้องใช้:** Mosquitto และ MariaDB ไม่ต้องติดตั้งลง Windows โดยตรง
แค่สั่ง Docker ให้ดึง "กล่องสำเร็จรูป" มารัน (บท 05 อธิบายละเอียด)

```powershell
winget install -e --id Docker.DockerDesktop
```

หรือ <https://www.docker.com/products/docker-desktop/>

### ขั้นตอนพิเศษ
1. Docker Desktop บน Windows ต้องใช้ **WSL 2** (Windows Subsystem for Linux)
   ถ้าตัวติดตั้งถาม ให้ติ๊ก "Use WSL 2"
   ถ้ายังไม่มี WSL ให้เปิด PowerShell แบบ **Run as Administrator** แล้วพิมพ์
   ```powershell
   wsl --install
   ```
   แล้วรีสตาร์ทเครื่อง
2. ต้อง **เปิด Virtualization ใน BIOS** (ส่วนใหญ่เปิดอยู่แล้ว)
3. หลังติดตั้ง ให้ **เปิดโปรแกรม Docker Desktop** และรอจนไอคอนวาฬที่มุมจอขึ้น "Engine running"

> ⚠️ ทุกครั้งที่จะรันโปรเจกต์ ต้องเปิด Docker Desktop ก่อน
> ถ้าลืม สคริปต์จะขึ้น `Docker Desktop ยังไม่ทำงาน กรุณาเปิด Docker Desktop แล้วรันสคริปต์ใหม่`

### ตรวจ

```powershell
docker --version
docker compose version
docker info
docker run --rm hello-world
```

`docker run --rm hello-world` ต้องขึ้นข้อความ `Hello from Docker!`

## 5. MariaDB — ฐานข้อมูล

มี 2 ทางเลือก **เลือกทางเดียว**

### ทางเลือก A: รันใน Docker (แนะนำ ง่ายและลบทิ้งง่าย)

`run_all.ps1` จะหา container ที่ **ชื่อมีคำว่า `mariadb`** แล้วสั่งเปิดให้เอง
จึงต้องตั้งชื่อ container ว่า `mariadb`

```powershell
docker run -d `
  --name mariadb `
  --restart unless-stopped `
  -e MARIADB_ROOT_PASSWORD=ตั้งรหัสที่นี่ `
  -e MARIADB_DATABASE=rmutt_save_energy `
  -e TZ=Asia/Bangkok `
  -p 3306:3306 `
  -v rmutt-mariadb-data:/var/lib/mysql `
  mariadb:11
```

อธิบายทีละส่วน

| ส่วน | ความหมาย |
|---|---|
| `docker run` | สร้างและเปิด container ใหม่ |
| `-d` | detached = รันเบื้องหลัง ไม่ค้างหน้าจอ |
| `--name mariadb` | ตั้งชื่อ container (ให้ `run_all.ps1` หาเจอ) |
| `--restart unless-stopped` | เปิดคอมใหม่แล้วให้เปิดเองอัตโนมัติ (ยกเว้นเราสั่งหยุดเอง) |
| `-e ชื่อ=ค่า` | ตั้ง environment variable ภายในกล่อง |
| `MARIADB_ROOT_PASSWORD` | รหัสของผู้ใช้ `root` ของฐานข้อมูล |
| `MARIADB_DATABASE` | สร้างฐานข้อมูลชื่อนี้ให้ตอนเปิดครั้งแรก |
| `-p 3306:3306` | เปิดพอร์ต 3306 ของ Windows → ต่อเข้าพอร์ต 3306 ในกล่อง |
| `-v rmutt-mariadb-data:/var/lib/mysql` | เก็บข้อมูลใน volume ชื่อ `rmutt-mariadb-data` ลบกล่องแล้วข้อมูลยังอยู่ |
| `mariadb:11` | ใช้ image MariaDB รุ่น 11 (รุ่นเดียวกับบนเซิร์ฟเวอร์จริง) |

แล้วใส่รหัสเดียวกันใน `backend/.env`

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=ตั้งรหัสที่นี่
DB_DATABASE=rmutt_save_energy
```

ตรวจ

```powershell
docker ps --filter name=mariadb
docker exec -it mariadb mariadb -uroot -p -e "SELECT VERSION();"
```

### ทางเลือก B: ติดตั้งบน Windows โดยตรง
ดาวน์โหลด MSI จาก <https://mariadb.org/download/> ตอนติดตั้งจะถามรหัส root
และพอร์ต (ใช้ 3306) มันจะรันเป็น Windows Service อัตโนมัติ
`run_all.ps1` จะแจ้งว่า "ไม่พบ container ชื่อที่มีคำว่า mariadb" แล้วข้ามไป ซึ่งถูกต้อง

> ⚠️ ห้ามมีทั้งสองแบบพร้อมกัน เพราะจะแย่งพอร์ต 3306

## 6. HeidiSQL — ดูฐานข้อมูลแบบมีหน้าจอ

```powershell
winget install -e --id HeidiSQL.HeidiSQL
```

หรือ <https://www.heidisql.com>

### เชื่อมต่อฐานข้อมูลในเครื่อง
1. เปิด HeidiSQL → **New** (มุมซ้ายล่าง)
2. Network type: `MariaDB or MySQL (TCP/IP)`
3. Hostname / IP: `127.0.0.1`
4. User: `root`
5. Password: รหัสที่ตั้งไว้
6. Port: `3306`
7. Databases: `rmutt_save_energy`
8. กด **Open**

> 💡 ถ้าอยากดูฐานข้อมูล **บนเซิร์ฟเวอร์จริง** ใช้ `.\db-tunnel.ps1` (บท 14)
> แล้วต่อที่พอร์ต `3307` แทน

## 7. Flutter SDK — สร้างแอป

**ทำไมต้องใช้:** แอปเขียนด้วย Flutter, `pubspec.yaml` กำหนด `sdk: ">=3.8.0 <4.0.0"`
(Dart 3.8 = Flutter รุ่น 3.32 ขึ้นไป) ติดตั้ง Flutter **stable ล่าสุด**

### ติดตั้ง
1. ไปที่ <https://docs.flutter.dev/get-started/install/windows>
2. ดาวน์โหลดไฟล์ zip ของ Flutter stable
3. แตกไว้ที่ `C:\src\flutter` (**ห้าม** แตกใน `C:\Program Files` เพราะต้องการสิทธิ์พิเศษ
   และห้ามมีเว้นวรรคหรือภาษาไทยใน path)
4. เพิ่ม `C:\src\flutter\bin` เข้า PATH
   - กด Start พิมพ์ `environment` → **Edit environment variables for your account**
   - เลือก `Path` → **Edit** → **New** → ใส่ `C:\src\flutter\bin` → OK
5. ปิดแล้วเปิด PowerShell ใหม่

> 💡 ถ้าใช้ VS Code: ติดตั้ง extension Flutter แล้วกด `Ctrl+Shift+P` → `Flutter: New Project`
> VS Code จะเสนอดาวน์โหลด SDK ให้

### ตรวจ

```powershell
flutter --version
flutter doctor
```

`flutter doctor` ตรวจทุกอย่างที่ Flutter ต้องใช้ และบอกว่าขาดอะไร เช่น

```text
[√] Flutter (Channel stable, 3.x.x)
[√] Windows Version
[X] Android toolchain - develop for Android devices
    X Unable to locate Android SDK.
[√] Chrome - develop for the web
[X] Visual Studio - develop Windows apps
    X Visual Studio not installed
[√] VS Code
[√] Connected device (3 available)
```

- `[√]` = พร้อม
- `[X]` = ขาด (ข้อความใต้บรรทัดบอกวิธีแก้)
- `[!]` = ใช้ได้แต่มีคำเตือน

ถ้าต้องการรายละเอียด: `flutter doctor -v`

## 9. Android Studio — สำหรับแอป Android

**ทำไมต้องใช้:** ได้ Android SDK, emulator และ JDK (ใช้ `keytool` สร้างกุญแจเซ็น APK)

```powershell
winget install -e --id Google.AndroidStudio
```

หลังติดตั้ง
1. เปิด Android Studio → ทำ Setup Wizard ให้จบ (จะดาวน์โหลด SDK)
2. **More Actions → SDK Manager → SDK Tools** ติ๊ก
   - Android SDK Command-line Tools
   - Android SDK Platform-Tools
3. ยอมรับ license

```powershell
flutter doctor --android-licenses
```

กด `y` ทุกข้อ

### สร้าง Emulator (มือถือจำลอง)
Android Studio → **More Actions → Virtual Device Manager → Create Device**
เลือกรุ่นใดก็ได้ เช่น Pixel 7 → เลือก system image → Finish

> ⚠️ Emulator **ไม่มี Bluetooth จริง** ทดสอบการตั้งค่า ESP32 ไม่ได้ ต้องใช้มือถือจริง

### ใช้มือถือ Android จริง
1. มือถือ: **ตั้งค่า → เกี่ยวกับโทรศัพท์** → แตะ "หมายเลขบิลด์" 7 ครั้ง → เปิดโหมดนักพัฒนา
2. **ตัวเลือกสำหรับนักพัฒนา** → เปิด **USB debugging**
3. ต่อสาย USB → มือถือถาม "อนุญาต USB debugging" → อนุญาต

ตรวจ

```powershell
flutter devices
```

ต้องเห็นชื่อมือถือ และ `Windows (desktop)`

## 10. Arduino IDE 2 + ESP32 — เขียนโปรแกรมลงบอร์ด

```powershell
winget install -e --id ArduinoSA.IDE.stable
```

หรือ <https://www.arduino.cc/en/software>

### 10.1 เพิ่มบอร์ด ESP32
1. **File → Preferences** → ช่อง **Additional boards manager URLs** ใส่
   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
2. **Tools → Board → Boards Manager** ค้น `esp32` → ติดตั้ง **esp32 by Espressif Systems**
   (ใช้รุ่นล่าสุดก่อน ถ้าคอมไพล์ไม่ผ่านเพราะไลบรารี IR ให้ลองลดรุ่นลง)

### 10.2 ติดตั้งไลบรารี
**Tools → Manage Libraries** (หรือ `Ctrl+Shift+I`) ค้นและติดตั้ง

| ไลบรารี | รุ่น | ใช้ในบอร์ด | ทำอะไร |
|---|---|---|---|
| **ArduinoJson** (Benoit Blanchon) | **6.x** (ห้าม 7.x) | ทั้งสอง | อ่าน/เขียน JSON |
| **PubSubClient** (Nick O'Leary) | ล่าสุด | ทั้งสอง | MQTT client |
| **IRremoteESP8266** (David Conran ฯลฯ) | **2.9.0** | แอร์ | ส่งสัญญาณ IR ยี่ห้อต่าง ๆ |
| **PZEM004Tv30** (Jakub Mandula) | ล่าสุด | แอร์ | อ่านมิเตอร์ไฟ PZEM-004T |
| **ld2410** (Nick Reynolds) | 0.2.2 ขึ้นไป | ตรวจคน | อ่านเรดาร์ LD2410 |

Wi-Fi, BLE, Preferences มากับบอร์ด ESP32 แล้ว ไม่ต้องติดตั้ง

> ⚠️ ArduinoJson ต้องเป็น **6.x** ในหน้า Library Manager ให้กด dropdown เลือกรุ่น 6.21.x
> ถ้าเผลอติด 7 จะคอมไพล์ผ่านแต่มีคำเตือน หรืออาจพัง

### 10.3 ไดรเวอร์ USB
เสียบบอร์ด ESP32 แล้วเปิด **Device Manager** → **Ports (COM & LPT)**
- ถ้าเห็น `Silicon Labs CP210x (COM5)` หรือ `USB-SERIAL CH340 (COM5)` = ใช้ได้
- ถ้าเห็นเครื่องหมาย ⚠️ หรือไม่เห็นเลย ต้องลงไดรเวอร์
  - ชิป CP2102: ค้น "CP210x USB to UART Bridge VCP Drivers" จาก Silicon Labs
  - ชิป CH340: ค้น "CH341SER driver" จาก WCH
- ดูชิปได้จากตัวอักษรบนชิปเล็ก ๆ ใกล้ช่อง USB ของบอร์ด
- ⚠️ สาย USB บางเส้นเป็น **สายชาร์จอย่างเดียว** ไม่มีสายข้อมูล ถ้าไม่ขึ้น COM ลองเปลี่ยนสาย

## 14. ติดตั้งไลบรารีของโปรเจกต์ (หลังติดตั้งเครื่องมือครบ)

เครื่องมือข้างบนคือ "ช่าง" แต่โปรเจกต์ยังต้องการ "อะไหล่" (ไลบรารี) ของตัวเองด้วย

### Backend

```powershell
cd backend
npm ci
```

- `npm ci` = ติดตั้งไลบรารี **ตามรุ่นที่ล็อกไว้เป๊ะ** ใน `package-lock.json`
  ลงโฟลเดอร์ `node_modules\`
- ต่างจาก `npm install` ที่อาจอัปเดตรุ่นเล็กน้อยและแก้ `package-lock.json`
- ใช้ `npm ci` เพื่อให้ได้ผลเหมือนกันทุกเครื่อง (เซิร์ฟเวอร์ก็ใช้ `npm ci --omit=dev`)

### แอป Flutter

```powershell
cd ..                 # กลับโฟลเดอร์หลัก
flutter pub get
```

- อ่าน `pubspec.yaml` แล้วดาวน์โหลดแพ็กเกจ (http, flutter_blue_plus, ...) ลงแคช
- สร้าง `.dart_tool\` และ `pubspec.lock`

ถ้ายังไม่มีโฟลเดอร์แพลตฟอร์ม (`windows\`, `android\`)

```powershell
flutter create --platforms=android,windows,web .
```

- `flutter create .` = สร้างไฟล์โครงโปรเจกต์ใน **โฟลเดอร์ปัจจุบัน** (`.`)
- `--platforms=...` = สร้างเฉพาะแพลตฟอร์มที่ระบุ
- **ไม่ทับ** โค้ดใน `lib\` ที่มีอยู่ เติมเฉพาะไฟล์ที่ขาด
