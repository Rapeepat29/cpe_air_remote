RMUTT Save Energy - อัปเดตหน้าตารางและหน้าควบคุม v1.8.2

สิ่งที่แก้ไข
1. แถบวันในหน้าจัดการตารางแสดงครบ 7 วัน ตั้งแต่อาทิตย์ถึงเสาร์
2. ไม่ต้องเลื่อนแถบวันเพื่อค้นหาวันเสาร์
3. แถบวันของหน้าตารางหลักและหน้าจัดการใช้รูปแบบเดียวกัน
4. หัวข้อ "เลือกห้องที่ต้องการควบคุม" เปลี่ยนเป็นแถบสีเขียวแบบเดียวกับหน้าอื่น
5. ปุ่มเฟืองจัดการห้องยังอยู่มุมขวาบน
6. ปรับสีหลัก พื้นหลัง เส้นขอบ การ์ด และสถานะให้เป็นชุดสีเขียวเดียวกัน
7. รองรับธีมสว่าง ธีมมืด ภาษาไทย และภาษาอังกฤษ

วิธีติดตั้ง
1. นำโฟลเดอร์ cpe_air_remote ไปวางทับโปรเจกต์เดิม
2. เปิด PowerShell ในโฟลเดอร์ cpe_air_remote
3. รันคำสั่ง:

flutter clean
flutter pub get
flutter test
flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

- ไม่ต้องแก้ฐานข้อมูล
- ไม่ต้องรัน Migration
- ไม่ต้องแฟลช ESP32 ใหม่
