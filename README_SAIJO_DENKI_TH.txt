============================================================

RMUTT Save Energy - Saijo Denki (App 3.4.1+21 / Firmware 1.8.1)

สิ่งที่เพิ่ม
1. หน้าเพิ่ม/ตั้งค่าแอร์มีตัวเลือก Saijo Denki
2. แอปและ Backend ใช้รหัสเดียวกันคือ SAIJO_DENKI
3. Firmware แยกส่ง Saijo ด้วย SaijoDenkiAC.cpp/.h
4. ยี่ห้อเดิมยังส่งผ่าน IRremoteESP8266 IRac เหมือนเดิม

คำสั่ง Saijo ที่รองรับจากข้อมูลที่จับไว้
- เปิดและปิด
- Cool, Dry และ Fan
- อุณหภูมิ 18-29 องศาเซลเซียส
- พัดลม Auto, 1, 2, 3 และ Turbo
- Swing Auto และตำแหน่ง 1-5

การแมปในแอป
- Low = พัดลม 1
- Medium = พัดลม 2
- High = พัดลม 3
- Turbo = พัดลมแรงสุด (ใช้ค่า fanSpeed: turbo ใน MQTT)
- Up = Swing 1
- Upper = Swing 2
- Middle = Swing 3
- Lower = Swing 4
- Down = Swing 5

บรรทัด UNKNOWN 1 bit ก่อนชุดโหมดเป็นสัญญาณรบกวน ไม่ใช่คำสั่ง Dry
เฟรม 72 บิตสามเฟรมถัดมาเป็น Dry, Fan และ Cool ตามลำดับและนำมาใช้แล้ว
Turbo แสดงในส่วนความเร็วพัดลม เพราะเฟรมที่จับได้เป็นสถานะพัดลมแรงสุด
ฟังก์ชันเสริมอื่นที่ยังไม่มีเฟรมสมบูรณ์จะไม่แสดงสำหรับ Saijo

ข้อจำกัดของข้อมูลที่จับมา
แต่ละคำสั่งเป็นแพ็กเก็ตเต็มจากสถานะรีโมตในตอนที่จับสัญญาณ จึงควรทดสอบกับ
แอร์จริงทีละปุ่มก่อน โดยเฉพาะการเปลี่ยนหลายค่าแล้วกดส่งพร้อมกัน หากพบว่าคำสั่งหนึ่ง
เปลี่ยนค่าอื่นตามไปด้วย ต้องจับข้อมูลเพิ่มเพื่อหาโครงบิตและ checksum ให้ประกอบสถานะ
ทั้งหมดได้อย่างอิสระ

วิธีแฟลช
1. ติดตั้ง ArduinoJson 6.x, PubSubClient และ IRremoteESP8266 2.9.0
2. เปิด firmware/rmutt_esp32_air/rmutt_esp32_air.ino
3. ห้ามแยก SaijoDenkiAC.cpp และ SaijoDenkiAC.h ออกจากโฟลเดอร์เดียวกับ .ino
4. แฟลช ESP32 แล้วเปิด Serial Monitor 115200
5. ต้องเห็น Firmware: 1.8.1

หลังแฟลช ให้เข้าหน้าตั้งค่าบอร์ดผ่าน Bluetooth แล้วเลือก Saijo Denki ก่อนบันทึก
เพราะบอร์ดเก่าที่เคยบันทึก Haier จะยังจำ protocol เดิมใน NVS จนกว่าจะตั้งค่าใหม่
