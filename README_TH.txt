RMUTT ESP32 Air Controller 1.6.0 - แก้เพิ่มอุปกรณ์ตัวที่ 2 บน Windows
====================================================================

ชุดนี้ใช้แตกทับโปรเจกต์ cpe_air_remote ชุดปัจจุบัน

หมายเหตุ (ต.ค. 2569): ไฟล์นี้เป็นบันทึกของรุ่น 1.6.0 เก็บไว้เป็นประวัติ
รุ่นปัจจุบัน: แอป 3.16.0+32, เฟิร์มแวร์แอร์ IR 2.5.1, สายแอร์ Daikin 2.5.2-slm8,
เซ็นเซอร์ LD2410 1.3.2 วิธีติดตั้งปัจจุบันดู START_HERE.md, README.md และ deploy/DEPLOY.md
ค่า MQTT ทั้งหมดมาจาก Backend แล้ว ไม่ต้องกรอก MQTT Host ในแอป และไม่ต้องใช้ --dart-define=MQTT_DEFAULT_HOST

ความสามารถ
-----------
- เปลี่ยนเมนูเป็น "ตั้งค่าบอร์ด"
- กดเมนูแล้ว Backend ส่ง MQTT action=enter_setup ไปยัง ESP32
- ESP32 เปิด BLE ชื่อ RMUTT-AC-... โดยไม่ต้องกดปุ่มที่บอร์ด
- แอปเปิดหน้าตั้งค่าเดียวกับการเพิ่มบอร์ดครั้งแรก
- เมื่อเข้าหน้าตั้งค่า บอร์ดยังคงต่อ Wi-Fi/MQTT และยังออนไลน์ตามปกติ
- เมื่อกดย้อนกลับ ค่าเดิมใน ESP32/NVS และฐานข้อมูลจะไม่ถูกล้าง
- แอปอ่านค่าเดิมจาก ESP32 มาใส่ให้ ได้แก่ ห้อง หมายเลขแอร์ ชื่อแอร์
  โปรโตคอล SSID, MQTT Host/Port/Username และเวลาเปิด-ปิด
- รหัสผ่าน Wi-Fi/MQTT จะไม่ถูกส่งกลับมาแสดง ให้เว้นว่างเพื่อใช้รหัสเดิม
- กรอก Wi-Fi, MQTT, ชื่อแอร์, โปรโตคอล และเวลาเปิด-ปิดใหม่ได้
- แอปตรวจ Device ID ให้เป็นบอร์ดตัวเดิม
- ESP32 ทดสอบ Wi-Fi ก่อนเขียน NVS
- ถ้า SSID/รหัสผ่านผิด ค่าเดิมจะยังอยู่และสามารถแก้แล้วกดบันทึกซ้ำได้
- หาก Wi-Fi เดิมเชื่อมไม่ได้ บอร์ดจะเปิด BLE Recovery อัตโนมัติ

วิธีติดตั้ง
-----------
1. ปิด Flutter และ Backend เดิมด้วย Ctrl+C
2. แตก ZIP แล้วนำทุกไฟล์ไปทับในโฟลเดอร์ cpe_air_remote
3. เปิด firmware/rmutt_esp32_air/rmutt_esp32_air.ino
4. อัปโหลดลง ESP32:
   Board: ESP32 Dev Module
   Partition Scheme: No FS 4MB (2MB APP x2)  (เฟิร์มแวร์ปัจจุบันใช้ partitions.csv ในโฟลเดอร์สเก็ตช์)
   Upload Speed: 115200
5. ตั้ง backend/.env ให้ MQTT_URL ชี้ไป Broker ที่ใช้งานจริง เช่น:
   MQTT_URL=mqtt://192.168.1.153:1883
6. เปิด Backend:
   cd backend
   npm install
   npm run dev
7. เปิดแอป:
   flutter clean
   flutter pub get
   flutter run -d windows --dart-define=API_BASE_URL=http://127.0.0.1:3000/api --dart-define=MQTT_DEFAULT_HOST=192.168.1.153

วิธีใช้
-------
1. เข้าไปที่ห้องและกดเมนูสามจุดของแอร์
2. เลือก "ตั้งค่าบอร์ด"
3. รอให้แอปค้นหาและเลือกบอร์ดตัวเดิมอัตโนมัติ
4. ตรวจค่าเดิมที่แอปอ่านมาจาก ESP32
5. แก้เฉพาะค่าที่ต้องการ รหัสผ่านเว้นว่างได้หากต้องการใช้ค่าเดิม
6. กด "บันทึกการตั้งค่าลง ESP32"
7. หากไม่ต้องการแก้ ให้กดย้อนกลับได้ บอร์ดจะไม่หลุดจาก Wi-Fi/MQTT

หมายเหตุ
--------
- ช่อง MQTT Host ใส่เฉพาะ IP เช่น 192.168.1.153
- ห้ามใส่ mqtt:// หรือ :1883 ในช่อง Host เพราะ Port มีช่องแยก
- ESP32 รองรับ Wi-Fi 2.4 GHz
- ถ้าบอร์ดออฟไลน์จนรับคำสั่ง MQTT ไม่ได้ ให้กด BOOT ค้างแล้วกด RESET
- เฟิร์มแวร์ในชุดนี้คือ 1.6.0 ต้องแฟลชไฟล์ .ino ใหม่นี้หนึ่งครั้ง
  เพื่อใช้ Identity packet แบบสั้นและแก้ BLE timeout บน Windows
- หลังแฟลชครั้งนี้ การเปลี่ยนค่าภายหลัง
  ไม่ต้องอัปโหลดโค้ดใหม่
