============================================================

RMUTT Save Energy - สร้างห้องอัตโนมัติจากตารางเรียน v1.8.5
============================================================

การทำงานใหม่
-------------
1. Admin เลือกไฟล์ Excel หรือ CSV ตารางเรียน
2. Backend อ่านข้อมูลทุกห้องที่มีตารางถูกต้อง แม้ตาราง rooms จะว่าง
3. หน้า Preview แยกห้องเดิมกับห้องใหม่ให้ตรวจสอบ
4. เมื่อ Admin กดยืนยัน ระบบจะสร้างห้องใหม่และนำเข้าตารางพร้อมกัน
5. หากขั้นตอนใดผิดพลาด Transaction จะย้อนกลับทั้งหมด

กฎการสร้างห้อง
---------------
- 16101 -> ชั้น 1, ลำดับ 1, ประเภท Classroom
- 16203 -> ชั้น 2, ลำดับ 3, ประเภท Classroom
- 16307 -> ชั้น 3, ลำดับ 7, ประเภท Classroom
- CL503 -> ชั้น 0 (Special), ลำดับ 503, ประเภท Special
- รหัสพิเศษอื่นที่ถูกต้องจะอยู่ชั้น 0

ความปลอดภัยของข้อมูล
--------------------
- ฟังก์ชันนี้ใช้ได้เฉพาะ Admin
- ไม่มีการสร้างห้องในขั้น Preview
- ต้องกดยืนยันก่อนสร้างห้อง
- นำเข้าแล้วแทนที่ตารางเฉพาะห้องที่อยู่ในไฟล์
- ห้องอื่น แอร์ ผู้ใช้ MQTT และการตั้งค่า ESP32 ไม่ถูกแก้ไข

ไม่ต้อง Migration ฐานข้อมูลและไม่ต้องแฟลช ESP32 ใหม่
